# Hybrid 性能与隐私预算

| 项目   | 目标值                | 说明                 |
| ---- | ------------------ | ------------------ |
| 触发评估 | < 5 ms / 秒视频       | 单次 pass 扫描关键点流     |
| 上行打包 | < 10% 离线管线总时长      | 包含关键点裁剪/可选视频       |
| 合并   | < 2 ms / rep       | 线性匹配               |
| 体积预算 | ≤ 5MB              | 默认配置               |
| 视频导出 | ≤ 10s / ≤15fps     | 仅在同意后启用            |
| 隐私级别 | keypoints_only（默认） | 视频上传需 consent=true |
