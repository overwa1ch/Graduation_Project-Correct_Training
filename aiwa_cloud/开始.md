# 🚀 从这里开始

## ⚠️ 重要提示

**所有命令都必须在 `aiwa_cloud\core-api` 目录下运行！**

---

## 📍 第一步：确认目录位置

打开 PowerShell，运行：

```powershell
# 检查当前目录
Get-Location

# 应该显示类似：...\aiwa_cloud\core-api

# 如果不在，进入正确目录
cd aiwa_cloud\core-api

# 再次检查
Get-Location
```

---

## 🔍 快速检查脚本

在 `aiwa_cloud` 目录下运行：

```powershell
.\检查目录.ps1
```

脚本会告诉你：
- ✅ 如果在正确位置，会提示"位置正确"
- ❌ 如果位置不对，会告诉你怎么修复

---

## 🚀 第二步：运行设置

进入 `core-api` 目录后：

```powershell
cd core-api

# 运行自动设置脚本
.\setup-sqlite.ps1
```

如果脚本失败，手动设置：

```powershell
# 1. 复制配置文件
Copy-Item env.sqlite.example .env
Copy-Item prisma\schema.sqlite.prisma prisma\schema.prisma

# 2. 生成密钥（运行两次，分别复制输出）
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# 3. 编辑 .env 文件，填入密钥

# 4. 安装依赖
npm install

# 5. 创建数据库
npx prisma db push

# 6. 启动
npm run dev
```
