# SQLite 快速开始（Windows）

> **最简单的方法，无需 Docker！**

---

## ⚠️ 重要提示

**所有命令都必须在 `aiwa_cloud\core-api` 目录下执行！**

---

## 🚀 方法 1：使用自动设置脚本（推荐）

### 步骤 1：打开 PowerShell，进入目录

```powershell
# 从项目根目录开始
cd aiwa_cloud\core-api

# 验证位置（应该显示路径包含 core-api）
Get-Location
```

### 步骤 2：运行设置脚本

```powershell
.\setup-sqlite.ps1
```

脚本会自动完成所有设置！

### 步骤 3：启动服务

```powershell
npm run dev
```

看到以下输出说明成功：
```
🚀 AIWA Auth API listening on port 3001
```

---

## 📝 方法 2：手动设置

### 步骤 1：打开 PowerShell，进入目录

```powershell
# 进入 core-api 目录
cd aiwa_cloud\core-api

# 验证：应该能看到这些文件
Get-ChildItem env.sqlite.example
Get-ChildItem prisma\schema.sqlite.prisma
```

如果看不到文件，说明不在正确目录！

### 步骤 2：复制配置文件

```powershell
# 复制环境变量模板
Copy-Item env.sqlite.example .env

# 复制 SQLite schema
Copy-Item prisma\schema.sqlite.prisma prisma\schema.prisma
```

### 步骤 3：生成 JWT 密钥

```powershell
# 生成第一个密钥（复制输出）
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# 生成第二个密钥（复制输出）
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### 步骤 4：编辑 .env 文件

用记事本打开 `.env` 文件，将上面生成的两个密钥填入：

```bash
JWT_ACCESS_SECRET=粘贴第一个密钥
JWT_REFRESH_SECRET=粘贴第二个密钥
```

### 步骤 5：安装依赖

```powershell
npm install
```

### 步骤 6：创建数据库

```powershell
npx prisma db push
```

### 步骤 7：启动服务

```powershell
npm run dev
```

## 🐛 常见错误

### 错误 1：找不到文件

```
Copy-Item : 找不到路径...因为该路径不存在
```

**原因：** 不在正确的目录下

**解决：**
```powershell
# 检查当前位置
Get-Location

# 如果路径不包含 core-api，进入目录
cd aiwa_cloud\core-api

# 再次检查文件是否存在
Get-ChildItem env.sqlite.example
```

### 错误 2：端口被占用

**解决：** 修改 `.env` 文件中的 `PORT=3002`（或其他端口）

### 错误 3：npm 命令不存在

**解决：** 安装 Node.js：https://nodejs.org/
