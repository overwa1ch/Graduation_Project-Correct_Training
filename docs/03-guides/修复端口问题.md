# 修复端口权限问题

## 问题

如果你看到这个错误：
```
Error: listen EACCES: permission denied 0.0.0.0:3001
```

**原因：** Windows 系统在端口 3000-3012 范围内有保留端口。

## ✅ 解决方案

### 方法 1：使用脚本自动修复（推荐）

```powershell
cd aiwa_cloud\core-api
.\fix-port.ps1
```

### 方法 2：手动修改 .env 文件

1. 打开 `core-api\.env` 文件
2. 找到 `PORT=` 这一行
3. 修改为：
   ```bash
   PORT=8080
   ```
4. 保存文件

### 方法 3：检查并选择其他端口

```powershell
# 检查 8080 是否可用
netstat -ano | findstr :8080

# 如果被占用，尝试其他端口：
# PORT=8081
# PORT=4000
# PORT=5000
```

## 📝 推荐的端口

- ✅ **8080** - 推荐，通常不被占用
- ✅ **8081** - 备选
- ✅ **4000** - 备选
- ⚠️ **5000** - 可能被占用

## 🚀 修复后启动

```powershell
npm run dev
```

应该看到：
```
🚀 AIWA Auth API listening on port 8080
🌐 Access at: http://localhost:8080
```

## 测试

```powershell
curl http://localhost:8080/health
```

应该返回 JSON 响应。
