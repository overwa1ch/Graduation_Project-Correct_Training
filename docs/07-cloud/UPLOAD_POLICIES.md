# UPLOAD_POLICIES.md
**Pre-signed Upload & Lifecycle Policies**  
**Version:** v1.0  
**Storage:** AWS S3 (SSE-S3 default, SSE-KMS optional)

---

## 1) Pre-signed Upload Flow

1. App requests `/v1/sessions` with desired `consent` scope (`keypoints` or `video+keypoints`).
2. API returns presigned URL(s) for `keypoints` and optionally `video`.
3. App `PUT` uploads directly to object storage (no API auth headers required).
4. App calls `/v1/sessions/{id}/finalize` with asset metadata (`sha256`, `size`, `content_type`).

**Validation:**
- Server verifies object presence in S3, size range, checksum (SHA-256).
- If mismatch, object is quarantined and not bound to session.

---

## 2) Security

**Presigned URL Constraints:**
- Expiration: ≤15 minutes
- Method: Only `PUT` allowed
- Content-Type: Restricted by server policy
- Scope: Per-object, single-use (first successful PUT invalidates URL)
- Server-side encryption (SSE-S3 default / SSE-KMS if audit required)

**Storage:**
- AWS S3 (configurable for MinIO/Supabase Storage compatibility)
- Encryption: SSE-S3 (default) / SSE-KMS (for key audit)
- Lifecycle: Unreferenced / expired objects auto-deleted after retention period

---

## 3) Retention & Deletion

**Default Retention:** 30 days, then purge if not linked to active session.

**User-initiated Delete:**
- Deletes DB rows and storage objects (idempotent)
- Cascades: session deletion → assets deletion → S3 object deletion

**Revoked Consent:**
- Remove `video.mp4` immediately
- Keep `keypoints.json` if allowed (if user only revoked video consent)

**Soft Delete:**
- Sessions marked `deleted_at` retained 7 days
- Hard delete (DB + S3) after 7 days

---

## 4) Quotas (P0)

**Per-user Limits:**
- Concurrent jobs limit: 3 (configurable)
- Max object size: `video ≤ 200MB`, `keypoints ≤ 20MB` (configurable via env vars)
- Rate limits: 60 requests per minute per user & per IP

**Multipart Upload:**
- Threshold: 8MB (configurable)
- Automatic multipart for large files

**Configuration (Environment Variables):**
- `VIDEO_MAX=200MB`
- `KEYPOINTS_MAX=20MB`
- `MULTIPART_THRESHOLD=8MB`

---

## 5) Object Storage Path Structure

```
s3://bucket/
users/{user_id}/sessions/{session_id}/
  keypoints.json          # required
  video.mp4               # optional, requires consent
  result.json             # optional, uploaded local result
  result_cloud.json       # generated by REINFER worker
  advice.json             # generated by ADVICE worker
```

**Access:** Direct presigned upload; download via presigned URLs or API proxied download.
