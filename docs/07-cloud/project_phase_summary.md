#### 3. 数据库设计 ✅
**已实现表结构：**

**admin-users 表**（管理员表）
```sql
- id: UUID (主键，自动生成)
- name: TEXT (姓名)
- email: TEXT (邮箱，唯一索引)
- password_hash: TEXT (密码哈希)
- is_system_admin: BOOLEAN (是否为系统管理员)
- is_active: BOOLEAN (账户是否启用)
- created_at: TIMESTAMP (创建时间)
- updated_at: TIMESTAMP (更新时间)
```

**admin-session 表**（会话表）
```sql
- id: UUID (主键，自动生成)
- user_id: UUID (外键 -> admin-users.id)
- session_token: TEXT (会话令牌，唯一)
- expires_at: TIMESTAMP (过期时间)
- created_at: TIMESTAMP (创建时间)
- 外键约束：级联删除
```

**技术亮点：**
- 使用 Drizzle ORM 实现类型安全的数据库操作
- 数据库迁移文件版本控制
- 关系定义清晰（外键约束）
- 索引优化（email 唯一索引）
